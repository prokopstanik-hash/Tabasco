Deployment Guide

  1. Create Repository: Create a new public repository on GitHub named telegram-clicker.
  2. Upload File: Save this exact code as index.html and push/upload it to your repository main branch.
  3. Enable Pages: Go to Settings -> Pages, set the Source branch to main, and click Save.
  4. Copy URL: Copy the live site link (e.g. https://username.github.io/telegram-clicker/).
  5. Create Telegram Bot: Open Telegram, search for @BotFather, send /newbot, and follow the setup prompts.
  6. Link Mini-App: Send /newapp to BotFather, choose your created bot, set the WebApp URL to your GitHub Pages link.
